# 地铁图查看器

纯静态看图页面，无框架、无构建、不上传任何数据。样式沿用你那份 `index.html` 的配色与组件风格（浅色/深色、胶囊标签、圆角卡片、Toast、回到顶部）。

## 目录

```
sv/
├── index.html    页面结构
├── style.css     样式（配色变量 + 组件 + 灯箱）
├── app.js        渲染、筛选、灯箱缩放/平移/翻页、主题、滚动
├── images.js     ★ 图片清单，加图只改这个
├── img/          图片放这里
└── README.md
```

## 加图

打开 `images.js`，往 `window.IMAGES` 里加一行：

```js
{ src: 'img/beijing.png', title: '北京地铁图', group: '线路图', badge: '2024' }
```

- `src` 相对路径，建议统一放 `img/`
- `title` 不填则取文件名
- `group` 相同的值会自动归成一个筛选标签
- `badge` 可选，卡片右上角小标签

图片多的时候批量生成条目：

```bash
ls img/ | sed "s|.*|  { src: 'img/&', title: '\\1', group: '线路图' },|"
```

把输出粘进 `images.js` 即可。

## 打开方式

**双击 `index.html` 就能开**，不用起服务。因为图片是你自己放的同目录本地文件，不涉及跨域。

（如果你以后改成从 CDN 或接口拉图片，就需要 `python3 -m http.server 8000` 起个静态服务了。）

## 操作

| 操作 | 方式 |
|---|---|
| 看大图 | 点卡片 |
| 缩放 | 滚轮 / `+` `-` / 灯箱按钮 |
| 平移 | 按住拖拽 |
| 翻页 | `←` `→` / 灯箱按钮 |
| 复位 | `R` |
| 关闭 | `Esc` / 点空白处 / ✕ |
| 筛选 | 顶部标签 |
| 换主题 | 右上角 🌙/☀️，记忆在本地 |

## 说明

- 图片加载失败时卡片会显示「图片未找到」，不会整页崩
- 清单为空时显示引导文案，告诉你往哪放图
- 图片仅供参考，实际运营以官方公布为准
